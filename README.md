Hello! My name is Benjamin Bagley, and this is a small repository of code and projects that I have worked on over the years.
Not all of the code here will represent my current knowledge, but it is more of a collection of things I'm proud to have made--given what I knew at the time. 

I'll also include a short description of each project in here just in case you want a little more info

speed_sim - I was playing a card game when I wondered "How often does a random deal lead to a certain outcome?" I had learned the basics of simulation recently, 
  so I decided to code up something to answer my questions. This was a passion project, and I'm really proud of how it turned out given that I hadn't really done
  any coding in R before this point. 

hw_simulation_intro - the very first probability simulation I made in R. 

HouseTempReport - I had 50000 data points of humidity and temperature measurements from several days in my home. I decided to put together a report to learn the 
  basics of Power BI, and this was the result.
